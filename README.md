#Concesionaria

Proyecto de aprendizaje para desarollar una aplicación web de gestion y venta de vehículos.

##Tecnologías

-HTML
-CSS
-JavaScript
-Node.js
-Express

### Como hacer funcionar mi API REST

para ejecutar el servidor, entra a la carpeta /backend desde consola y ejecutá npm install. Luego npm run dev.
Con esos pasos usted va a descargar las dependencias necesarias para que pueda andar correctamente como se pensó que funcione la API.
